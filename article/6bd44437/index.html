面向对象编程（基础）

类与对象

  • 类：把事物的所有属性抽象出来，形成了类，是一种数据类型，如：猫类，狗类
  • 对象：具体的实例的特点，包括其属性和行为，通过类来创建对象
    成员变量 = 属性 = 字段 = field
    行为 = 成员方法

类的内存分布

类先把自己的基础信息加载到方法区(只加载一次)，然后根据方法区类信息进行内存空间的分配，基本数据类型存放在堆里面，引用数据类型(如String)在堆中存放地址，指向方法区的常量池。
真正的对象是在堆里面(如下图堆中0x0011粉色块)，栈中的称为对象引用。举例：Cat cat1 = new Cat();，其中cat1是对象引用，new Cat() 创建的对象空间（数据）才是真正的对象！

注意：如下例所示，当栈中有main栈，New1栈时，如果二者同时都有对cat1的定义时，一方置空不会影响另一方的数据，因为只是删除了引用链条（由形参带入形成）；当New1中new Cat();时，此时New1中的cat1不是仅仅有指向原cat1，而是在堆中又重新创建了一个新的对象，对新对象的修改同样也不会影响main中原来的对象。

成员方法

  • 定义
  • 传参机制
    基本数据类型，传递的是值（浅拷贝），形参的变化不影响实参；
    引用类型，传递的是地址（传递也是值，但是值是地址），可以通过形参影响实参

递归

每递归一次都会开辟一个递归工作栈。

方法重载

Java中允许同一个方法名，有不同的参数，成为多个同名方法，称为方法重载(OverLoad)。
要求：方法名必须相同，形参列表必须不同，返回类型无要求。

可变参数

  • 基本概念
    Java允许将同一个类多个同名同功能但参数个数不同的方法，封装成一个方法，通过可变参数来实现。
  • 基本语法
  • 使用细节
  1. 可变参数的实参可以为 0 个或任意多个；
  2. 可变参数的实参可以为数组；
  3. 可变参数的本质就是数组；
  4. 可变参数可以和普通类型的参数一起放在形参列表，但必须保证可变参数在最后；
  5. 一个形参列表中只能出现一个可变参数

作用域

  • 赋值
    全局变量可以不赋值直接用，局部变量必须赋值后才能使用，因为没有默认值。
  • 作用域范围不同
    全局变量 / 属性：可以被本类使用，或其他类使用（通过对象调用）
    局部变量：只能在本类中对应的方法中使用
  • 修饰符不同
    全局变量 / 属性可以加修饰符，局部变量不可以加修饰符

构造方法/构造器

  • 基本介绍
    构造方法又叫构造器(constructor)，是类的一种特殊的方法，它的主要作用是完成对新对象的初始化，而不是创建对象。
    它有几个特点：1. 方法名和类名相同； 2. 没有返回值； 3. 在创建对象时，系统会自动的调用该类的构造器完成对对象的初始化。
  • 基本语法

说明：

  1. 构造器的修饰符可以默认
  2. 构造器没有返回值
  3. 方法名 和 类 名字必须一样
  4. 构造器的调用由系统完成
  • 举例代码
  • 使用细节
  1. 一个类可以定义多个不同的构造器，即构造器重载
    比如：我们可以再给 Person 类定义一个构造器，用来创建对象的时候，只指定人名，不需要指定年龄
  2. 构造器名和类名要相同
  3. 构造器没有返回值
  4. 构造器是完成对象的初始化，并不是创建对象
  5. 在创建对象时，系统自动的调用该类的构造方法
  6. 如果程序员没有定义构造方法，系统会自动给类生成一个默认无参构造方法 (也叫默认构造方法)，比如 Person (){}，可以使用[[Java杂记#javap指令]] javap 指令进行查看。
  7. 一旦定义了自己的构造器，默认的构造器就被覆盖了，不能再使用默认的无参构造器，除非显式的定义一下，即自己定义一下Person (){}

对象创建流程

  1. 加载 Person 类信息 (Person.class)，只会加载一次
  2. 在堆中分配空间 (地址)
  3. 完成对象初始化 [3.1 默认初始化 age=0 name=null 3.2 显式初始化 age=90,name=null, 3.3 构造器的初始化 age =20, name = 小倩]
  4. 将对象在堆中的地址，返回给 p (p 是对象名，也可以理解成是对象的引用)

this

当使用构造器时，如果构造器参数列表使用和属性变量相同的名字，JVM就会根据就近原则使其成为局部变量，无法初始化赋值，所以就需要this来保证可以进行赋值。

this 在内存中


可以看到，this相当于是一个隐藏的指向自己的属性。JVM会给每个对象分配this，代表当前对象。this指代的是谁？哪个对象调用就指哪个。

使用细节

  1. this 关键字可以用来访问本类的属性、方法、构造器；
  2. this 用于区分当前类的属性和局部变量；
  3. 访问成员方法的语法：this. 方法名 (参数列表)；
  4. 访问构造器语法：this (参数列表); 注意只能在构造器中使用（即只能在构造器中访问另外一个构造器，而不能在普通方法中使用构造器）；
  5. this 不能在类定义的外部使用，只能在类定义的方法中使用。
